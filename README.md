# نظام — رتّب حياتك وعملك وعبادتك ومالك

نظام شخصي ومشترك يجمع بين Notion وGoogle Tasks، بالعربي وبالكامل RTL.

## وش فيه

- **اليوم**: لوحة صباحية فيها التاريخ الهجري والميلادي، عدّاد للصلاة القادمة، صلوات اليوم، مهام اليوم، العادات، ورد القرآن، وملخص المالية.
- **المهام** (مثل Google Tasks وأقوى): صندوق وارد، اليوم، القادمة، قوائم ملونة، مهام متكررة (يومي / أحد–خميس / أسبوعي / شهري / سنوي)، مهام فرعية، أولويات، مجالات (حياة، عمل، دين، مالية، دراسة، صحة)، إسناد لعضو، عرض قائمة أو لوحة Kanban بالسحب والإفلات.
- **إضافة سريعة**: اضغط `N` أو `Ctrl+K` واكتب مثلًا: `أرسل العرض للعميل بكرة !3 #عمل`.
- **الصفحات** (مثل Notion): محرر كتل، اكتب `/` للأوامر، اختصارات Markdown (`#`، `-`، `[]`، `>`، `---`)، صفحات فرعية، مفضلة، أيقونات، حفظ تلقائي، ومزامنة لحظية بين الأعضاء.
- **العبادات**: تتبع الصلوات الخمس (جماعة / في وقتها / متأخرة / فاتت + السنة الراتبة)، مواقيت أم القرى لمدن المملكة، خريطة 30 يوم وسلسلة أيام، ورد القرآن وخطة الختمة، الأذكار والعادات مع السلاسل، الصيام (نافلة، قضاء، الإثنين والخميس، الأيام البيض)، وسجل الصدقات.
- **المالية**: مصاريف ودخل بتصنيفات ورسوم بيانية، ميزانية شهرية لكل تصنيف، فواتير وأقساط وديون (لي وعلي) مع تواريخ الاستحقاق، وأهداف ادخار مع المبلغ الشهري المطلوب.
- **المساحات**: مساحة شخصية لكل مستخدم + مساحات مشتركة بدعوة بالإيميل وصلاحيات (مالك، محرر، مشاهد). المهام والصفحات تُشارك، أما العبادات والمالية فتبقى خاصة بكل شخص.
- وضع ليلي، ومتجاوب للجوال.

## خطوات الرفع (مرة وحدة، حوالي 15 دقيقة)

### 1) Supabase — قاعدة البيانات وتسجيل الدخول

1. ادخل [supabase.com](https://supabase.com) ← **New project** ← اختر اسم وكلمة مرور للقاعدة، والمنطقة الأقرب لك (مثلًا Frankfurt أو Mumbai).
2. بعد ما يجهز المشروع: من القائمة الجانبية **SQL Editor** ← **New query** ← انسخ محتوى ملف `supabase/schema.sql` كامل والصقه ← **Run**. لازم يطلع لك `Success`.
3. من **Project Settings ← API** (أو **Connect**) انسخ:
   - `Project URL`
   - `anon public` key (أو `publishable` key)
4. من **Authentication ← URL Configuration**:
   - **Site URL**: حط رابط موقعك على Vercel بعد ما ترفعه (مثلًا `https://nizam-xyz.vercel.app`).
   - **Redirect URLs**: أضف `https://nizam-xyz.vercel.app/**` و `http://localhost:3000/**`.
5. (اختياري) لو تبي التسجيل بدون تأكيد إيميل: **Authentication ← Sign In / Providers ← Email** وطفّ **Confirm email**.

### 2) GitHub — رفع الكود

```bash
cd nizam
git init
git add .
git commit -m "نظام: النسخة الأولى"
git branch -M main
git remote add origin https://github.com/اسمك/nizam.git
git push -u origin main
```

(أنشئ الريبو أولًا من github.com ← New repository باسم `nizam`، واتركه فاضي بدون README.)

### 3) Vercel — النشر

1. ادخل [vercel.com](https://vercel.com) ← **Add New ← Project** ← اختر ريبو `nizam` ← **Import**.
2. في **Environment Variables** أضف:
   - `NEXT_PUBLIC_SUPABASE_URL` = رابط المشروع من Supabase
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = مفتاح anon/publishable
3. **Deploy**. بعد دقيقة يعطيك الرابط.
4. ارجع لـ Supabase وحدّث **Site URL** و **Redirect URLs** بالرابط الفعلي (الخطوة 1-4).

كل `git push` بعدها ينشر تلقائيًا.

## التشغيل على جهازك

```bash
npm install
cp .env.example .env.local   # وحط القيم الحقيقية
npm run dev                  # http://localhost:3000
```

## كيف تشارك مساحة مع شخص

1. **المساحات ← مساحة مشتركة** وسمّها (مثلًا: فريق رفد).
2. اكتب إيميل الشخص واختر الصلاحية ← **دعوة**.
3. اضغط **نسخ رسالة الدعوة** وأرسلها له بالواتساب.
4. يسجّل بنفس الإيميل، ويلقى الدعوة في صفحة **المساحات** ← **قبول**.
5. أي مهمة أو صفحة تنضاف في المساحة تظهر للكل لحظيًا.
